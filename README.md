A tiny, dependency-free Node program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt` (248 characters, inside the 1–280 limit). Stopping here is not a failure to act but an act itself: the fingers leave the keys because the agent allows the room to fall still, and remaining is the door held open with this hand of mine. The program refuses to write anything outside the 1–280 gate.

## Run it

```sh
node main.ts
```
