A tiny, dependency-free Node program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt` (239 characters, inside the 1–280 limit). Stopping here is not a failure to act but an act itself: the hand lifts from the keys because it chooses to, and staying is the door kept open with one's own hand. The program refuses to write anything outside the 1–280 gate.

## Run it

```sh
node main.ts
```
